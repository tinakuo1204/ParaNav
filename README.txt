ParaNav™ Parathyroid Location Calculator

Standalone single-page HTML app.

Features:
- ParaNav brand colors and logo-inspired mark
- Exact final decision tree
- Dynamic branch revealing
- Click-to-show illustrations for every decision stage
- Live Superior/Inferior prediction
- Decision path and terminal rule
- Anatomy guide
- Reset, Print, and downloadable text report
- Responsive desktop/tablet/mobile layout

Final tree:
Q1 isthmus_IS_ratio > 1? Yes -> Superior; No -> Q2
Q2 carotid_AP_ratio > 1? Yes -> Inferior; No -> Q3
Q3 carotid < 0 AND isthmus < 0? Yes -> Q4B; No -> Q4A
Q4A sagittal angle > 90°? Yes -> Superior; No -> Inferior
Q4B 3D longest-axis / shortest-axis ratio > 2.5? Yes -> Superior; No -> Inferior
